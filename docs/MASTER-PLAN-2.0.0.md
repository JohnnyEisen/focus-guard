# 卷宗体系重构总纲（2.0.0）

> 原则：一次检测全程复用，卷宗留痕指纹防伪，跨平台适配不重复取证
>
> （工程总纲，非法条；对应引擎 `hooks/guard.mjs` v2.5.1；卷宗结构沿用 2.0.0 设计）

## 一、核心定位

1. 项目未开源，无外部用户，旧格式直接废弃，不写兼容层，不写迁移脚本。
2. 版本号 1.0.0 → 2.0.0，不兼容变更，一次性重构到位。
3. Git 历史可重写，强制推送允许。

## 三、环境检测（会话级，一次检测全程生效）

检测时机：SessionStart 执行一次，写入 `state.envCache`；`envCache` 非空即代表"已检测"，不再另设布尔标记（原 `envChecked` 只写不读、且可能与缓存不一致，2.5.1 删除）。UserPromptSubmit 不重检。仅当明确探测到 shell 变化时重检。检测结果同时写入卷宗【一】的环境声明行，供人类直接查阅（2.5.1）。

检测项：

- 操作系统（Windows / macOS / Linux）
- Shell 与版本（PowerShell 7.6.6 / zsh 5.9 / bash 5.2）
- 默认编码（UTF-8 / GBK / UTF-16）
- 路径分隔符（\ 或 /）
- 文件系统大小写敏感（是 / 否）
- BSD 工具检测（sed/grep/awk 是否为 BSD 版本）
- 可用命令（grep / sed / awk / gsed / greadlink）

## 四、不重复读校验流程

```text
读取请求
   |
   v
查卷宗记录
   +-- 无记录 ---------> 首次读取 -> 记录 mtime/size/hash/TTL
   +-- 有记录 ---------> mtime + size 比对
         +-- 不一致 ----> 拦截免读资格，放行真重读（更新指纹）
         +-- 一致 ------> SHA-256 校验（≤200KB）
               +-- 不一致 -> 拦截免读资格，放行真重读
               +-- 一致 ---> Git diff 校验
                     +-- 有变更 -> 拦截免读资格，放行真重读
                     +-- 无变更 -> TTL 校验
                           +-- 未超 -> 免重读放行（复用已有取证）
                           +-- 超时 -> 拦截免读资格，放行真重读
```

## 五、自适应 TTL

| 变更历史 | TTL |
|---|---|
| 30 天未变 | 7 天 |
| 7 - 30 天未变 | 24 小时 |
| 7 天内有变 | 2 小时 |
| 首次遇到 | 4 小时（保守） |
| 项目依赖声明覆盖 | 按声明 TTL（如游戏本体 60 天） |
| 人工标注覆盖 | 按标注 TTL（稳定 30 天 / 活跃 1 小时） |

优先级：项目依赖声明 > 人工标注 > 自适应 TTL。

## 六、跨平台命令拦截

Windows（PowerShell 会话）：

- 禁 bash 语法（\| head / \| grep / \| wc / \| sed / \| awk / &&）
- 禁裸 cat/grep/wc
- 强制 UTF-8
- 用 Get-Content / Select-String / Measure-Object

macOS：

- 禁 sed -i 不带 ''
- 禁 grep -P
- 禁 readlink -f
- 大小写不敏感下禁仅大小写不同的重名文件

Linux：标准 GNU 工具，无特殊限制。

## 七、插件钩子逻辑

- SessionStart：读取卷宗 + 环境检测（若未检测）；重建 readSetCache 与 TTL 表
- UserPromptSubmit：重置任务级状态（预算/违规），保留侦查缓存；加载平台规则集
- PreToolUse：环境规则检查 → 盲写检查 → 大文件拦截 → Grep head_limit
- PostToolUse：更新侦查记录与 TTL；记录有效/无进展；更新额度台账
- Stop：证据锚点检查 → 熔断声明检查 → 未交代则打回

## 八、预期效果

1. 跨回合不重复读已取证文件（指纹一致即放行）。
2. 稳定依赖（游戏本体/SDK）一次声明，长期免重读。
3. 时间戳伪造（git checkout / cp -p / touch -d）无法绕过校验。
4. 环境切换被识别，规则自动适配，不污染既有配置。
5. 会话级检测不占任务预算，不受任务污染。

一句话：卷宗管档案，环境管适配，指纹管真伪，TTL 管时效。
